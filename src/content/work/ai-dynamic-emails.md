## The shape of the bet

LLM-assisted email composition was the obvious AI move for a sales-engagement platform. The risk wasn't whether it could be built; it was whether what got built would be *good enough that reps trusted it.*

## What I drove

- **Quality gates.** Partnered tightly with engineering on model evaluation and prompt refinement. Set a bar for tone, brevity, and personalization that we tracked formally before shipping each iteration.
- **Surface choice.** Composition embedded in the existing rep email-write flow, not a separate "AI mode." The point was to lift the floor, not introduce a switch.
- **Observability.** Instrumented usage and outcome (acceptance, edit-rate, reply-rate) so we could see which prompt versions actually helped reps.

## Outcome

Shipped. Improved the email-write loop without breaking the rep's existing muscle memory.
